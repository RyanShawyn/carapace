# Carapace 0.1.4

安装包：https://github.com/RyanShawyn/carapace/releases/latest

## 新增

- 菜单栏乌龟图标可以隐藏：「设置 → 通用」里的「在菜单栏显示图标」，或主窗口 App 菜单里的同名开关。
- 三种恢复方式：App 菜单 →「显示菜单栏图标」、设置 → 通用、启动 App 时按住 Option；
  也可以用 `carapace settings set --key showMenuBarIcon --value true`。
- 隐藏只影响菜单栏图标，持仓提醒仍会写入通知列表并弹系统通知。

## 安装

下载 `Carapace-0.1.4.dmg`，把 `Carapace.app` 拖进 Applications。ad-hoc 签名，首次打开需右键 → 打开。

App 内会自动检查并更新；也可以在设置 → 更新里手动检查。SHA-256 见 Release 页面。

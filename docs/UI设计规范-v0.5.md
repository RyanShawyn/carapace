## 0. 这套 UI 解决什么

把「看持仓、做计划、记成交、复盘、看通知」压进四个入口，减少重复页面；AI 不占一个导航，而是全局侧栏；通知不占一个导航，而是铃铛抽屉。

统一性三条硬约束：

1. 所有页面共用一套 token、表格、卡片、按钮、空状态和错误状态。
2. 所有 AI 内容统一为「AI 芯片 + 草稿 + 确认」，不出现第二种写法。
3. 所有写入都有一次确认；自动化只做读取、整理和草稿。

## 1. 设计原则

| 原则 | 落地 |
|---|---|
| 数字优先 | 先结论数字，再解释；价格、盈亏、仓位全部等宽数字 |
| 一屏一件事 | 总览看组合，详情看单只，复盘看一次判断 |
| 少入口 | 4 个侧边栏入口；AI 和通知用全局浮层 |
| 自动化不越界 | 自动刷新、整理、草稿；交易与计划写入确认 |
| 记忆可见 | 引用记忆带编号，可点开证据，可编辑/归档 |
| 颜色只表达语义 | 涨跌红绿、警告琥珀、强调蓝；不做装饰色 |
| 失败不阻塞 | 行情/AI 失败只提示，手动流程完整 |
| 中文短句 | 按钮动词开头，不写感叹号，不写营销文案 |

## 4. 全局布局

### 4.1 菜单栏面板

- 只读，650 宽；列与现有面板一致，表头最右加 24pt ↗。
- 行点击进详情；提醒最多 2 条；行情异常行 `—`。
- 右键严格三项。

### 4.2 主窗口

- 标题栏 52：红绿灯、页面标题、⌘K、AI、铃铛、刷新、新建。
- 侧边栏 196：品牌 + 4 入口 + 网关状态。
- 内容区：页面内边距 20/24/26。
- 关闭窗口不退出；Dock/菜单栏可重开。

### 4.3 AI 侧栏

- 固定右侧 396，顶部 64，底部 18；不跳页，⌘J 切换。
- 头部：AI 芯片、标题、当前模型、展开、关闭。
- 上下文条：当前标的/复盘/组合；框架名。
- 内容：快捷指令、消息、工具活动、记忆引用、草稿卡。
- 底部：composer；⌘↩ 发送，Esc 关闭。
- 展开后进入全屏对话（同一组件，无新导航）。

### 4.4 通知抽屉

- 固定右侧 396；铃铛打开。
- 头部：未读数、全部已读、关闭。
- 筛选：全部/未读/价格/复盘/AI 与草稿。
- 行：未读点、标题、描述、类型、时间。
- 底部：通知设置。

## 5. 组件

### 5.1 按钮

| 类型 | 用途 | 规则 |
|---|---|---|
| Primary | 当前页唯一主操作 | 保存/确认/导入 |
| Secondary | 次要操作 | 取消/编辑/导出 |
| Ghost | 低优先级 | 关闭/查看 |
| Danger | 不可逆 | 清仓，二次确认 |
| Small / XS | 卡片/表格内 | 24 / 21 高 |

每屏最多一个 Primary；同一行不出现两个 Primary。

### 5.2 输入

- 32 高，圆角 7；聚焦蓝边 + 3px 光晕。
- 标签在输入框上方，10.5 号 muted。
- 数字等宽；金额千分位。
- 错误用页面 banner 或 sheet 内说明，不在输入框下挤红字。

### 5.3 表格

- 表头 29，行 37–42；空值 `—`。
- 整行可点击；行内按钮阻止冒泡。
- 已清仓/已归档降低透明度。
- 持仓列比例：名称 1.7 / 现价 .8 / 涨跌 .8 / 今日 .9 / 总盈亏 .9 / 持仓 .8 / 成本 .7 / 仓位 .6 / 下一档 1。
- 模型表：模型 1.7fr / 供应商 90 / 能力 1.2fr / 上下文 62 / 推理 92 / 收藏 24。

### 5.4 卡片、Banner、空状态

- 卡片圆角 10、边框 1、内边距 14–16；不叠阴影。
- Banner：Info 蓝、Amber 警告、Red 不可逆；不阻塞。
- 空状态：图标 + 一句标题 + ≤2 行说明 + 1 主操作 + 1 次操作。

### 5.5 AI 组件

| 组件 | 规则 |
|---|---|
| AI 芯片 | 蓝底白字 `AI`，9.5/800，圆角 5 |
| 草稿卡 | 标题 + 变更列表 + 接受/放弃；标注基准版本 |
| 记忆引用 | 小 chip，点击打开记忆详情；显示编号 |
| 工具活动 | 一行「已读取 … · 只读」+ 脉冲点 |
| 模型徽标 | 显示名 + 供应商；点击进模型目录 |

### 5.6 模型目录

- 左侧供应商列表：全部 + magpie/OpenAI/Anthropic/Google/Ollama + 添加。
- 顶部搜索、能力筛选（全部/收藏/工具/推理/本地）、数量。
- 行：名称/id、供应商、能力 badge、上下文、推理档位、收藏星。
- 详情：协议、端点、上下文、输出、能力、测试、设为任务模型。
- 所有模型来自 `/v1/models`，不内置清单。

### 5.7 任务路由

- 表格：任务、场景、模型下拉、推理档位、回退。
- 任务：对话/建仓/计划复核/复盘/简报/提醒解释/风险检查。
- 模型下拉只列收藏 + 常用；可去目录选全部。
- 失败自动回退；连续失败提示。

### 5.8 分析框架卡

- 卡片：图标、名称、启用、描述、问题/指标/模板数量、用于多少持仓。
- 详情：建仓问题、关键指标（自动/手动）、计划模板、复盘问题、风险规则。
- 内置只读；复制后可改。

### 5.9 记忆卡

- 类型 pill（原则/偏好/模式/教训/事实/待验证）、标题、范围。
- 内容 2 行、证据、置信度、使用次数。
- 点击开详情；可编辑、归档、标记待复核。

### 5.10 Sheet / Modal

- 通用 560；宽版 760；最大 84vh。
- 头 48、底 52；Esc/✕/点击遮罩关闭；未保存先确认。
- 底部：取消在左，主操作在右，危险最右。
- 同一时间只允许一个 sheet。

### 5.11 Toast / 系统通知

- Toast 底部居中，1.9 秒，只做轻反馈。
- 系统通知 330 宽，右上角，7 秒；动作查看/稍后/确认。

## 6. 页面规范

### 6.1 总览

结构：

1. 标题 + 行情时间 + 自动刷新状态。
2. 可选行情/风险 banner。
3. 4 指标：总市值、今日、本周、仓位/风险。
4. 两栏：需要你处理（合并待办、草稿、记忆、提醒）+ 本周结果（盈亏、贡献/拖累、执行、回撤、AI 小结）。
5. 持仓表。
6. 自动化状态条（可点设置）。

规则：

- 不再单独放「今日待办 / 最近提醒 / 收盘小结」三块重复内容。
- 行情不完整时合计盈亏显示 `—`。
- 需要你处理最多 5 条，按严重度排序；每条可点击。
- AI 小结是一句话 + 下一步，不写长文。

### 6.2 持仓

顶部：标题 + 总市值/仓位/前三大 + 分段（持仓/计划/流水）+ 记一笔 + 新建。

- 持仓：筛选（持仓中/已清仓/全部）+ 表 + 风险两卡。
- 计划：标的/框架、版本、档位、下一档、下次复盘、状态；底部组合检查。
- 流水：持仓流水/提醒归档；筛选、导出、导入交割单。
- 已清仓行 62% 透明度 + pill。

### 6.3 持仓详情

头部：名称 + 代码 + 持仓中 + 框架 chip；数量/成本/现价/市值/仓位/今日；sparkline；操作：问 AI、记一笔、编辑、清仓。

标签：计划 / 流水 / 复盘（不设 AI 标签）。

计划：

- 计划版本 + 下次复盘 + 状态 + 问 AI / AI 复核 / 手写编辑。
- 档位表；已执行只读。
- 核心逻辑 + 失效条件。
- 分析档案卡：框架 + 4 个指标（值/来源/更新时间）+ 查看框架/补充数据。
- 最近流水。
- 右侧 AI 复核卡：结论、风险、建议变更、保存为新版本/只看不改；无复核/离线各有空态。

流水：表 + 导出 + 说明「只追加」。
复盘：最新复盘摘要 + 打开复盘 + AI 助手摘要；无复盘空态。

### 6.4 复盘

顶部：标题 + 3 待复盘/9 记忆 + 分段（复盘/记忆/风格）+ 生成本周简报。

复盘：

- 左侧待复盘/已完成列表；右侧详情。
- 详情：标题、状态、框架 chip、事实（框架指标）、结果归因、对话式复盘、判断文本、AI 摘要、下次日期、补充数据/据计划更新/完成。
- 对话式复盘：引用 2–3 条记忆；AI 问 2–3 个问题；用户回答；AI 归纳；记忆提案卡（勾选，确认后写入）。
- 结果归因：已实现、未实现变化、贡献、最大回撤。
- 已完成复盘对话只读。

记忆：

- 说明 banner：记忆是理解不是定义；有证据/置信度；可编辑/归档。
- 筛选：全部/全局/框架/标的/持仓；新增记忆。
- 两列记忆卡。
- 记忆设置：引用、自动提议、90 天提醒、导出/清空。

风格：

- 我的投资风格：AI 叙述 + 6 指标 + 更新快照。
- 体系·原则、最近教训、待验证。
- 快照保留历史，用来看风格变化。

### 6.5 设置 · AI 模型

- 网关卡：状态、地址、模型数、供应商数、协议标签、刷新、添加供应商。
- 子页：模型目录 / 任务路由 / 接入示例 / 安全与用量。

模型目录：

- 供应商列表 + 搜索 + 能力筛选 + 23+ 模型表。
- 行点击详情；收藏星；模型详情含协议/端点/能力/测试。
- 说明模型来自 `/v1/models`；无工具降级。

任务路由：

- 7 个任务；每个选模型 + 推理 + 回退。
- 按框架覆盖说明；不改变模型路由。

接入示例：

- 5 个页签：magpie / OpenAI / Anthropic / Gemini / Ollama。
- curl + SDK 片段、Base URL、认证头、模型 id；复制。
- 添加供应商 4 步说明。

安全与用量：

- 上下文范围、草稿-only 锁定、请求审查、月度用量表。

### 6.6 设置 · 分析框架

- 说明：框架决定建仓问题、计划模板、复盘指标；可手写。
- 5 个内置 + 自定义卡；卡上显示问题/指标/模板数量和用于多少持仓。
- 框架详情：建仓问题、关键指标（自动/手动）、计划模板、复盘问题、风险规则；复制/设为默认。
- 「框架如何影响」表：建仓/计划/复盘/AI 提示/可覆盖。

### 6.7 设置 · 自动化

- Banner：自动化只做读取、整理和草稿；写入确认。
- 自动完成：行情刷新、框架推断、计划草稿、复盘、简报、档位匹配、交割单导入、低风险草稿自动应用（默认关）。
- 交互提速：快速建仓、自动展开 AI 草稿、批量接受、提醒自动确认（默认关）。
- 规则表：触发 → 自动动作 → 确认。

### 6.8 设置 · 通知

- 开关：价格、止损、复盘、行情、仓位/回撤、收盘、周报。
- 免打扰、登录启动、系统权限、测试。
- 通知规则表：类型/渠道/去重。

### 6.9 设置 · 行情与数据

- 行情源：东财/新浪间隔、优先级、交易时段、采样保留、刷新。
- 状态：最后成功、备用源、持仓代码、请求预算、退避。
- 账户与交割单：默认账户、最近导入、导入按钮、自动导入。
- 数据库：路径、版本、备份、权限、打开/备份/校验/导出。
- 清理：AI 会话、采样、提醒归档。

### 6.10 新建持仓

- 顶部：快速/完整切换。
- 快速：代码 + 风险预算 + 框架（自动推断）→ AI 生成仓位与计划 → 一次确认。
- 完整 5 步：标的（代码/名称/现价/来源/框架/想法/已有持仓）→ 逻辑（框架问题 + 四问）→ 仓位（总资金/风险/止损/建议数量/上限）→ 计划（框架模板，可增删改）→ 确认（持仓/计划/风险/复盘 + 三项确认）。
- 右侧 AI 对话随框架变化；手动模式隐藏 AI，表单照常。
- 保存创建持仓、计划、change、复盘待办。

### 6.11 导入交割单

- 宽 760，四步：选择文件 → 字段映射 → 预览校验 → 完成。
- 文件卡：文件名、行数、识别列数、账户、币种。
- 账户/导入方式（成交编号/字段哈希）。
- 映射表：券商字段 → 标准字段 → 自动/待选；保存映射。
- 预览表：日期/代码/方向/数量/价格/金额/状态；可导入/重复/待确认/错误。
- 计数：将导入/重复跳过/待确认；下载错误行。
- 说明：重建持仓周期、不覆盖手工流水、按批次回滚。
- 结果页：批次、对账、回滚。

## 7. 交互规则

### 7.1 导航

- 侧边栏只 4 项；AI/通知不占导航。
- 持仓内分段切换不改变侧边栏选中。
- 深链：`carapace://overview`、`position/1?tab=plan`、`reviews?tab=memory`、`settings/ai?tab=catalog`、`import`。
- 通知点击走深链；面板行点击走详情。

### 7.2 AI

- 全局开关 + 按功能开关；关闭后不初始化网络。
- 任务路由选模型；失败回退；无工具降级。
- 草稿状态：pending → applied / discarded / stale / failed。
- 应用前校验版本/数量；冲突不覆盖。
- 记忆提议：勾选确认；原则/偏好确认后才写入；事实可自动。
- 引用记忆必须显示编号和证据入口。
- 请求审查可看实际发送内容。

### 7.3 计划

- 手写不依赖 AI；AI 只预填/复核。
- 保存先 diff；冲突不合并。
- 已执行档位只读；执行状态由流水派生。
- 档位价格/数量/条件校验；买入高于现价只提示。

### 7.4 成交与导入

- 成交数量/价格 > 0，卖出不超持仓；计划外提示。
- 导入先生成批次，预览后提交；错误/重复不静默导入。
- 导入不覆盖手工流水；整批可回滚。
- 修正走编辑持仓并填原因。

### 7.5 复盘与记忆

- 复盘事实只读；指标缺失标「待补充」。
- 对话式复盘先听用户，再总结；AI 不代替用户判断。
- 记忆提案有证据和置信度；用户可编辑/归档/取代。
- 完成后可生成计划草稿；不直接改计划。

### 7.6 通知

- 价格提醒只在穿越时触发；持续触及不重复。
- 免打扰只保留止损。
- 确认只影响状态栏，不改数据。
- 系统通知点击带深链。

### 7.7 自动化

- 自动：刷新、推断、匹配、创建复盘、整理事实、简报、草稿、记忆检索、风格指标。
- 确认：交易、计划写入、记忆原则/偏好、导入提交。
- 所有自动动作可在设置里关闭；有日志可查。

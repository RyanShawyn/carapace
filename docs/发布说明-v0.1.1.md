# Carapace 0.1.1

安装包：https://github.com/RyanShawyn/carapace/releases/latest

## 修复

- 「全部已读」后通知不再被下一轮行情刷新立刻重建；提醒条件持续期间，读过的提醒保持已读。条件消失后再次触发会作为新提醒出现。
- 计划草稿的待确认提醒读过一次后不再重复出现。

## 新增

- 通知分类开关：加仓/卖出档到价、停止买入档、观察标的到关注价、复盘到期、行情异常、仓位超限、计划草稿待确认、版本更新提示，可分别关闭。
- 设置 → 通知里显示 macOS 通知权限状态，并提供「打开系统设置」入口。

## 安装

下载 `Carapace-0.1.1.dmg`，把 `Carapace.app` 拖进 Applications。ad-hoc 签名，首次打开需右键 → 打开。

App 内会自动检查并更新；也可以在设置 → 更新里手动检查。SHA-256 见 Release 页面。

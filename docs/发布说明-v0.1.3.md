# Carapace 0.1.3

安装包：https://github.com/RyanShawyn/carapace/releases/latest

## 新增

- 计划可以移除：CLI 用 `plans remove --position <id> --yes`，界面在计划页点「移除计划」。
  只删除计划档位，持仓或观察标的保留，移除动作会写入流水。
- 持仓和观察列表的右键菜单增加「清仓…」「移除观察…」，不必先进入详情页。
- 股票没有硬删除，移除即清仓；观察标的是硬删除，会连带删除计划、指标和提醒，已记录的复盘保留。

## 安装

下载 `Carapace-0.1.3.dmg`，把 `Carapace.app` 拖进 Applications。ad-hoc 签名，首次打开需右键 → 打开。

App 内会自动检查并更新；也可以在设置 → 更新里手动检查。SHA-256 见 Release 页面。
